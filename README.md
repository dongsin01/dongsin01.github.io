# Dongsin Kim's Website

Personal academic CV website built with [Hugo](https://gohugo.io/).

## About

Dongsin Kim is a graduate student in the Department of Physics at Sogang University, working on electronic structure calculations and many-body interactions in solids under the supervision of [Prof. Young Woo Choi](https://yw-choi.github.io/).

## Site Structure

- **Home** — Brief introduction
- **About** — Bio, research interests, affiliations
- **Education** — Academic background and timeline
- **Research** — Research topics and methods
- **Publications** — Papers, preprints, and presentations
- **Contact** — Email, GitHub, ORCID, address

## Tech Stack

- **Hugo** static site generator with a custom minimal-academic theme
- **GitHub Actions** for automatic build and deployment to GitHub Pages

## Local Development

```bash
hugo server
```
